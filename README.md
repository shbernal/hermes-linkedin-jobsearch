# hermes-linkedin-jobsearch

A [Hermes Agent](https://hermes-agent.nousresearch.com) profile distribution for a job search built on LinkedIn: it finds postings, researches companies, tailors resumes, submits Easy Apply with your approval and tracks applications. It is not usable yet: the profile installs, but the skills are still being written. The decisions behind it are in [docs/adr](docs/adr/README.md).
